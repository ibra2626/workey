# SF-06 — Birleşik kabul ve ürün dokümanları

Durum: taslak. Bağımlılık: SF-01..05.

## İş

- Disposable SQLite ve örnek kitap verisiyle tam akış: başlat → yenile →
  yer imi bırak → başka cihaz → eski işe devam veya bugünü seç → bitir →
  geri al. Gerçek sunucu restart'ı ve Istanbul gece yarısı senaryosu.
- İki sekme çakışması; save_plan değiştir/sil koruması; eski MCP Complete;
  telafi bağlantıları; çok kaynak/uzun blok; hata ve tekrar deneme.
- 320x844, 390x844 ve 1280x800; klavye/fokus, reduced-motion, JS kapalı,
  gerçek %200 zoom. Önceki WKY-20 zoom işi kendiliğinden kapatılmaz.
- PRODUCT.md ve DESIGN.md'yi uygulanan davranışa eşitle; eski repo-boş
  ifadelerini düzelt. Onaylı nihai kararları DECISIONS.md'ye tarih/kaynakla yaz;
  CURRENT.md ve bu görev durumlarını gerçekten yapılan iş kadar güncelle.
- Sonuçları docs/ altında tek kabul raporunda kaydet; açık sınırlamaları belirt.

./bin/tailwindcss.exe -i web/styles/input.css -o web/static/app.css --minify.

go test ./internal/config/... ./internal/clock/... ./internal/store/... ./internal/plan/... ./internal/web/... ./internal/api/... ./internal/apidoc/... ./internal/mcpserver/... ./cmd/...

go build ./...; PowerShell ortamında CGO_ENABLED=0 ile ayrı go build ./...;
go vet ./...; gofmt -l . (boş); git diff --check.

go run golang.org/x/vuln/cmd/govulncheck@v1.9.0 ./... — bulgular ayrıca raporlanır.
